# Twin Cities Traffic: Analyzing and Predicting I-94 Traffic Volume
We will try to predict hourly traffic volume using this data. This will
be my main focus and we will check how well our predictions are.

The secondary goal is to use weather in improving predictions. I will
check whether using weather is good for improving predictions of the
traffic volume. "Good" is defined as reduction in prediction error
on unseenm data.

I will use the mean absolute error equation to estimate the reduction on
error where MAE is the sum of the absolute differences between actual
and predicted values divided by the number of data points. (Lower
MAE means predictions are better)
